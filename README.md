## Featured projects

### 🔒 [Cloud-Native Intrusion Detection System](https://github.com/SiddarthaNanuvala/Cloud-IDS-project)
Network anomaly detection service on the CIC-IDS2017 dataset, built to be deployable and observable.

- **FastAPI** inference service with `/health` and Prometheus `/metrics` endpoints
- **Docker** image with health check; **Kubernetes** manifests with probes, HPA (1–10 replicas) and optional KEDA scaling
- Load testing with **Locust** (500 concurrent users); **GitHub Actions** workflow
- Models: Isolation Forest (v1) and PyTorch autoencoder (v2)

### 🧠 [RAG Document Q&A API – BNP Paribas Cardif use case](https://github.com/SiddarthaNanuvala/A5_Pi2_Project_BNP_Paribas)
ESILV Pi2 project: question answering over private documents with source-grounded answers.

- **FastAPI** with two routers: document embedding and RAG question answering
- Chunking (1,000 chars, 200 overlap), Google embeddings, **FAISS** vector index with metadata
- Top-3 retrieval + **Gemini** with a custom prompt template; returns answer and sources
- Reproducible Python environment with **uv**

### 🛒 [Full-Stack E-Commerce Platform](https://github.com/SiddarthaNanuvala/EcommerceApp-Project)
Angular + PostgreSQL application, containerised with Docker.
